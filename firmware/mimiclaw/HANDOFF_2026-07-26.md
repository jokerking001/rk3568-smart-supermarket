## 已验证现象

- 订单任务可由 Work7_20 成功发送给打印机，曾显示 `ok #...`。
- 热敏标签纸用高温烙铁可以变灰黑，标签为可打印热敏材料。
- 商品/打印数据流不再是当前主要阻塞点。
- 机械上：黑色胶辊未安装时，按 SW2，小齿轮能动；胶辊安装并受打印头簧片压紧时，机构容易震动/卡住。标签纸为带离型底纸的模切标签，白色标签和底纸间有厚度台阶。
- 用户确认把打印头向后移开时，机构可转；热敏头簧片压紧时容易使滚轮停滞。不要让热敏头直接压裸胶辊，应让标签纸夹在打印头和胶辊之间。

## 当前严重阻塞：5V 电源故障

当前不是程序问题。ESP32-S3 启动后在 Wi-Fi 初始化阶段循环重启，串口日志多次出现：

```text
E BOD: Brownout detector was triggered
TG1WDT_SYS_RST
```

实测：

- `+5V`（U5.3、L6.1）约 `1.2~1.3V`，异常。
- `3.3V`（U5.2）接近 `0V`，为 5V 异常的连带结果。
- 用户称 U11 开关节点读到 12V；不能把 U11.2 当作 5V 输出。
- `L6.1` 才是真正 `+5V` 输出，已测得约 1.3V。
- 断电后测 `+5V` 对地，读数由几十千欧升到 `OL`（用户写作“0L”），这通常表示电容充电后开路，不像直接短路。

网表供电链路：

```text
12V 输入 -> U11 降压 -> D4/L6 -> +5V -> U5 -> 3.3V -> ESP32-S3
```

网表关键引脚：

- U5.1 = GND
- U5.2 = 3.3V 输出
- U5.3 = +5V 输入
- U11.1 = 12V 输入
- U11.2 = 高频开关节点（连接 L6.2 / D4.2，不是稳定 5V）
- U11.4 = +5V 反馈/输出检测
- L6.1 = +5V 输出

## 明天优先排查步骤

1. 不接 USB、不接 12V，测 D4 二极管档：
   - 红表笔接 D4 无横杠端，黑表笔接有横杠端，应约 0.15V 到 0.5V。
   - 表笔反接应为 `OL`。
   - 两向接近 0V：D4 短路；两向 OL：D4 开路/虚焊/未接触到焊盘。
2. 确认 L6 两端低阻导通（用户已反馈 L6 正常）。
3. 通电时测 DC 输入中心对外圈是否约 12V；再测 U11.1 对 GND 是否约 12V。
4. 若输入 12V 正常，但 L6.1/U11.4 仍约 1.3V，检查 U11、D4、L6 及周围电感/电容焊点；优先怀疑 U11 降压电路失效、D4 错误或虚焊。
5. 在 +5V 恢复稳定到约 5V、3.3V 恢复稳定到约 3.3V 前，不要继续运行电机或打印测试。
6. 电源修复后，先验证串口出现：

```text
WiFi ready, IP=192.168.43.76
```

再继续做：标签纸路径、走纸量校准、加热脉冲和实际打印黑度测试。

## 烧录命令

在 `firmware/thermal-printer/build`：

```powershell
& 'C:\Espressif\tools\python\v5.5.4\venv\Scripts\python.exe' -m esptool --chip esp32s3 -p COM20 -b 115200 --before default_reset --after hard_reset write_flash '@flash_args'
```

如果无法进入下载模式：按住 BOOT，短按 RESET，松开 RESET；连接成功后再松开 BOOT。低波特率 115200 比 460800 稳定。
